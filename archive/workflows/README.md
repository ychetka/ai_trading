# Archived workflows

The n8n workflow snapshots of the retired SMC era are intentionally not
published here: they are generated artifacts (exported JSON dumps) whose
embedded prompt/message strings were in Russian, and their live content
duplicates what `archive/tools/` + `archive/docs/` already describe.

- The SMC AI Analyst pipeline (v3→v4.5): archive/docs/description_v3.md,
  description_v4.3.md, description_v4.4.md, description_v4.5.md
- The deterministic engine code (Trade Calc equivalent):
  archive/tools/eql_monitor.js, screener.js, sqz_rank.js
- Backtests that falsified the approach: archive/tools/backtest_*.js
